# Лабораторная работа № 2

Моделирование приготовления лакокрасочных материалов. Отдельная версия с простым оформлением на HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` в браузере. Все четыре файла приложения должны лежать рядом. Сервер, Python, Node.js и установка библиотек не нужны. После скачивания можно работать без интернета.

На телефоне нажмите «Показать параметры», чтобы открыть меню и исходные данные.

## Содержание

Главная со схемой смесителя, теория, математическая модель, расчёт с графиками, оптимизация, таблица экспериментов и выводы. В таблице есть шесть базовых опытов; можно добавлять свои и скачивать CSV.

## Файлы

- `index.html` — разметка и текст отчёта;
- `styles.css` — оформление;
- `model.js` — H, E, C и оптимизация;
- `app.js` — события, графики и результаты;
- `test-model.cjs` — проверка расчётного ядра, запуск `node test-model.cjs` при наличии Node.js.

## Формулы

H = 100(1 − exp(−knt)), E = n²t.

При k=0,001 и цели 95% оптимум: n≈149,7866 об/мин, t=20 мин, E≈448720,5927 усл. ед.

Алгоритм: q=−ln(1−Hцель/100)/k; если q>10000, решения нет. Иначе n=max(100,q/20), t=max(1,q/n). Скорость и время непрерывны; при округлении надо повторно проверить H.

V не входит в формулу H и используется в модели концентрации: T=V/(G₁+G₂), P=(G₁C₁+G₂C₂)/(G₁+G₂), C=P+(C₀−P)exp(−t/T).

Опыты сохраняются только в текущем браузере, если доступен localStorage. При недоступном хранилище — до закрытия страницы. Сохранение этой версии отделено от других проектов. Перенос результатов между устройствами — через CSV.
